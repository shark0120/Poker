# 短劇德州撲克 — 遊戲企劃書（v0.1）

> 狀態：規劃階段，尚未開始寫程式。
> 目標：做一款「短劇風」主題的線上多人德州撲克，玩遊戲幣、免登入可玩、註冊後可累積積分換造型，打牌過程有大量角色台詞、動畫與音效，強調情緒價值。

---

## 0. 一句話定位

**「一桌牌，一齣戲。」**
把短劇裡最有梗的配角請到牌桌旁當荷官、陪玩、毒舌解說，讓每一手 All-in、每一次 Bad beat 都像短劇高潮反轉一樣有戲。

## 1. 重要前提：IP 與素材風險（開工前必須先決定）

「紅果短劇」是字節跳動旗下的短劇平台，平台上的劇集、角色、台詞、配樂版權分別屬於各製作方與平台。直接使用：

| 素材 | 風險 | 建議做法 |
|---|---|---|
| 平台名稱、Logo、UI 風格 | 商標、不正當競爭 | 不要在產品名與商店頁用「紅果」字樣；可用「短劇風」「爽劇風」等描述 |
| 具體劇集角色（名字、形象、劇照） | 著作權 + 肖像權（演員） | 設計**原創配角**，只致敬「短劇常見人設」（霸總助理、惡毒女配、贅婿岳母等） |
| 劇中台詞逐字引用 | 著作權 | 改寫成「梗」而非原句（例：「這位先生，你的卡被凍結了」→「這位先生，你的籌碼被凍結了」） |
| 劇中配樂 / BGM | 音樂著作權 + 錄音著作權 | 自製或購買授權的「短劇風」配樂（戲劇感鋼琴、反轉鼓點、抖音流行風格） |

**兩條路：**
- **A. 致敬路線（建議 MVP 採用）**：全部原創，風格致敬短劇。零授權成本，可隨時上架。
- **B. 正版授權路線**：若之後想用真實劇集 IP，需與紅果 / 製作方談授權，再把內容包成「聯名劇集包」用積分或付費解鎖。架構上要預留「主題包」可熱更新的設計。

本企劃以 **A 路線** 為基準，所有角色與台詞皆為原創設定。

## 2. 目標玩家與體驗目標

- **主要客群**：20–40 歲、手機為主、會看短劇、想要輕鬆社交牌局的玩家。
- **體驗核心**：
  1. 零門檻：點開就能打，不用註冊。
  2. 社交：三秒開好友桌、分享連結入桌。
  3. 情緒價值：每個關鍵時刻都有角色「接話」，輸也輸得好笑、贏也贏得浮誇。
  4. 收集感：註冊後打牌累積積分，兌換造型，展示在牌桌上。
- **明確不做**：真錢、儲值買幣（第一版）、博弈性質的兌現。遊戲幣與積分皆無現金價值。

## 3. 核心玩法

### 3.1 規則
- 標準無限注德州撲克（No-Limit Texas Hold'em）。
- 2–9 人桌（好友桌最多 9 人，匹配桌預設 6 人）。
- 完整規則：盲注、按鈕輪轉、四輪下注、邊池（Side pot）、攤牌比牌、平分彩池。
- 行動計時：預設 15 秒，超時自動 Check / Fold；每人每局有 2 次「加時 30 秒」。
- 離線保護：斷線後保留座位 2 手牌，期間自動 Fold；回來即可續打。

### 3.2 桌型

| 桌型 | 進入方式 | 盲注 / 買入 | 特色 |
|---|---|---|---|
| **匹配桌（快速開局）** | 大廳選級別 → 自動配桌 | 新手 10/20（買入 1k–4k）、進階 50/100、高手 500/1000 | 任何人隨時加入 / 離開，缺人補機器人（標示為「NPC」） |
| **好友桌（私人房）** | 房主建房 → 分享 6 碼房號或連結 | 房主自訂盲注、買入、人數、計時、是否允許觀戰 | 房主可踢人、設密碼、暫停；支援「飯局模式」（積分不計入排行榜） |
| **觀戰席** | 任一桌皆可觀戰 | 無 | 可看公開牌、看角色台詞、發表情；不能看底牌 |

### 3.3 機器人（NPC）
- 匹配桌人數不足時用 NPC 補位，NPC 頭上明確標示。
- NPC 直接用短劇配角人設（見第 6 章），風格對應打法：
  - 「惡毒女配」→ 激進 bluff。
  - 「保安大叔」→ 緊手，只打大牌。
  - 「贅婿」→ 前期裝弱，後期反殺。
- NPC 贏的籌碼不進任何玩家的積分。

## 4. 帳號系統

### 4.1 訪客（免登入）
- 第一次開啟自動建立「訪客 ID」存在裝置（localStorage / 裝置金鑰）。
- 隨機短劇風暱稱（例：「路人甲 #4821」「被潑咖啡的群演」）。
- 可玩匹配桌與好友桌，可領每日免費遊戲幣。
- **不累積積分、不能兌換造型、換裝置資料就沒了**。
- 牌桌上會常常收到溫柔提示：「註冊就能把今天的高光時刻存下來」。

### 4.2 註冊帳號
- 方式：Email + 密碼、Google / Apple 一鍵登入（第二階段再加 LINE / 手機號）。
- **訪客轉正**：註冊時把訪客的遊戲幣、暱稱、本局戰績一併繼承，避免玩家覺得「白打」。
- 擁有：積分、造型倉庫、好友列表、戰績統計、排行榜。

### 4.3 權限對照

| 功能 | 訪客 | 註冊 |
|---|---|---|
| 匹配桌 / 好友桌 | ✅ | ✅ |
| 每日免費遊戲幣 | ✅（較少） | ✅（較多 + 連續登入加成） |
| 積分累積 | ❌ | ✅ |
| 造型兌換 / 裝備 | ❌（只能用預設） | ✅ |
| 好友列表 / 戰績 | ❌ | ✅ |
| 排行榜 | ❌ | ✅ |

## 5. 經濟系統

兩種資源，刻意分開，避免「積分變賭資」：

### 5.1 遊戲幣（Chips）— 用來上桌
- **用途**：買入、下注。
- **取得**：
  - 新手禮包：10,000。
  - 每日簽到：訪客 2,000 / 註冊 5,000（連續 7 天加碼）。
  - 破產救濟：籌碼低於最低買入時，每 4 小時可領一次「救濟金」（短劇梗：「岳母打來的生活費」）。
  - 看完一段「角色小劇場」廣告位（第二階段，可選）。
- **不可**：玩家間轉帳、兌現。

### 5.2 積分（Drama Points, DP）— 用來換造型
- **只有註冊玩家累積**，且與輸贏籌碼脫鉤，主要獎勵「參與」與「高光」：

| 行為 | 積分 |
|---|---|
| 完成一手牌（打到攤牌或棄牌皆算） | +1 |
| 贏下一手 | +3 |
| 贏下底池 ≥ 50 BB 的大鍋 | +10 |
| 攤牌成牌：葫蘆 / 四條 / 同花順 / 皇家同花順 | +5 / +20 / +50 / +200 |
| Bad beat（攤牌時持有葫蘆以上卻輸） | +15（安慰獎） |
| 每日任務（例：「在匹配桌打 20 手」） | +20～50 |
| 好友桌每局結算 | 每人 +5（防刷：同一組人每天上限） |

- **防刷機制**：
  - 同一 IP / 裝置群組的好友桌每日積分上限。
  - 手數過短（<30 秒一手）的桌不計積分。
  - 與 NPC 的對局積分減半。

### 5.3 賽季
- 每 8 週一個賽季，主題換一批「劇集」（例：S1《豪門贅婿》、S2《重生之我在牌桌當霸總》）。
- 賽季限定造型賽季結束後下架，增加收集動機。

## 6. 主題包裝：短劇配角宇宙（原創）

### 6.1 角色定位
每個角色有三個職責：**牌桌語音（台詞）**、**NPC 人設（打法）**、**可兌換造型（語音包 / 頭像框 / 入場動畫）**。

| 角色 | 人設梗 | 牌桌上的職責 | 代表台詞（原創改寫） |
|---|---|---|---|
| **總裁特助 · 阿Ken** | 永遠拿著平板、一秒處理千萬合約 | 荷官 / 開局播報 | 「總裁，牌桌已經準備好了。」「這位先生的籌碼……已經被凍結了。」 |
| **惡毒女配 · 白薇薇** | 冷笑、抱臂、永遠不服 | 嘲諷對手、Bluff 旁白 | 「就這？」「你以為你贏了？戲才剛開始。」 |
| **贅婿 · 林默** | 表面窩囊，實則隱藏身分 | 翻盤 / Bad beat 反轉旁白 | 「三年了，是時候讓你們看看我真正的實力。」 |
| **岳母 · 王美鳳** | 拍桌、碎念、心疼錢 | 破產救濟、棄牌提醒 | 「又輸了？這些錢夠我買幾斤排骨！」「別硬撐，棄了棄了。」 |
| **保安大叔 · 老周** | 看破一切的門口守衛 | 緊手 NPC、超時提醒 | 「年輕人，別衝動。」「時間到了，該走了。」 |
| **閨蜜 · 小桃** | 高八度的吃瓜第一線 | 公共牌翻開時的驚呼 | 「天哪！！！」「姐妹你看到了嗎？！」 |
| **系統音 · 重生系統** | 機械女聲、任務播報 | 每日任務、成就解鎖 | 「叮——宿主已完成任務：連贏三手。」 |
| **會所經理 · Tony** | 油滑、懂事 | 入桌歡迎、換桌引導 | 「貴賓，這邊請，老位子給您留著。」 |

### 6.2 台詞觸發設計原則
- 每個事件準備 **3–6 句**輪播，避免重複感。
- 台詞分「公播」（整桌都聽到）與「私語」（只有當事人聽到，例如你拿到 AA 時系統音悄悄說「宿主，這把穩了……大概」）。
- 台詞可被玩家在設定中調整頻率：**全開 / 僅高光 / 關閉**。
- 台詞以字幕 + 語音同時呈現，語音第一版可用 TTS 做 placeholder，後期再配音。

### 6.3 音樂設計
- **大廳 BGM**：輕快短劇片頭風，30 秒 loop。
- **牌桌 BGM**：低調，隨底池大小切層（Adaptive music）：
  - 小鍋：鋼琴 + 輕打擊。
  - 底池 > 30 BB：加入弦樂。
  - 有人 All-in：鼓點 build-up，攤牌前靜音 1 秒（短劇反轉前的「停頓」）。
- **Stinger（短音效）**：
  - 反轉音（Bad beat / 逆轉）：經典短劇「噔噔噔」。
  - 打臉音：清脆巴掌聲（用在 Bluff 被抓）。
  - 霸總出場音：低音 + 風聲。

## 7. 動畫特效與音效事件表

> 這是「情緒價值」的核心。每個事件 = 動畫 + 音效 + 角色台詞。設計原則：**高光時刻要誇張，日常動作要輕快不拖時間**。

| 事件 | 觸發條件 | 動畫特效 | 音效 | 角色台詞（範例） |
|---|---|---|---|---|
| 入桌 | 玩家坐下 | 座位亮燈、頭像滑入、裝備的「入場動畫」播放 | 迎賓音 | Tony：「貴賓，這邊請。」 |
| 發底牌 | 每手開始 | 牌從荷官處飛出，落牌有輕微彈跳 | 發牌「唰唰」聲 | 阿Ken：「各位，請看牌。」 |
| 拿到強起手牌（AA/KK） | 私密，只有自己看到 | 底牌微微發光一下 | 低音「嗡」 | 系統音（私語）：「宿主，別笑出來。」 |
| Check | 玩家過牌 | 手指敲桌 | 敲桌聲 | — |
| 下注 / 加注 | 籌碼推入 | 籌碼堆飛入底池，數字跳動 | 籌碼碰撞聲 | 偶發：白薇薇：「哦？有點意思。」 |
| 大額加注（≥ 底池 2 倍） | — | 螢幕輕震、籌碼砸出火花 | 重擊聲 | 白薇薇：「你確定？」 |
| **All-in** | 任一玩家全下 | 全桌變暗、聚光燈打在該玩家、籌碼全部推出、「ALL IN」字樣劈入 | 鼓點 build-up + 風聲 | 林默：「是時候了。」 |
| 跟注 All-in（兩人以上攤牌） | — | 雙方頭像對撞分鏡，中間裂開 | 碰撞音 | 小桃：「要打起來了！！」 |
| 翻牌 / 轉牌 / 河牌 | 公共牌翻開 | 牌翻轉，若改變領先者則有閃光 | 翻牌聲；若反轉則「噔噔噔」 | 小桃：「天哪！！！」 |
| 全下時勝率顯示 | 攤牌 All-in | 顯示各方勝率條，隨公共牌即時變化 | 心跳聲（勝率接近時） | 老周：「年輕人，心跳穩一點。」 |
| 棄牌 | 玩家蓋牌 | 牌滑回荷官，座位變灰 | 輕滑聲 | 岳母：「棄了好，棄了好。」 |
| 贏小鍋 | 底池 < 20 BB | 籌碼飛向贏家 | 收籌碼聲 | — |
| **贏大鍋** | 底池 ≥ 50 BB | 金幣雨、贏家頭像放大、「霸總附體」特效 | 勝利 stinger | 阿Ken：「總裁，這筆款項已入帳。」 |
| **Bad beat** | 攤牌持葫蘆以上卻輸 | 畫面灰階、慢動作、下雨、輸家頭像碎裂 | 「噔噔噔」+ 雨聲 | 林默：「三年之期已到……可惜不是你。」 |
| Bluff 成功（下注把人全嚇跑且自願亮牌） | 玩家亮出垃圾牌 | 亮牌 + 「打臉」特效打在棄牌者頭像上 | 巴掌聲 | 白薇薇：「就這？」 |
| Bluff 被抓 | 攤牌輸且牌很差 | 被抓者頭像冒冷汗 | 尷尬音 | 岳母：「我就說你不行。」 |
| 連贏 3 / 5 手 | — | 頭像加「連勝火焰」，等級隨連勝升高 | 升級音 | 系統音：「叮——宿主已連勝三手。」 |
| 連輸 3 手 | — | 頭像出現小雨雲 | — | 岳母：「要不要先去吃個飯？」 |
| 行動倒數 < 5 秒 | — | 倒數圈變紅、閃爍 | 滴答聲 | 老周：「時間到了……」 |
| 超時自動棄牌 | — | 牌自動滑走 | — | Tony：「貴賓睡著了？」 |
| 破產 | 籌碼歸零 | 畫面變暗、出現「岳母打來的電話」彈窗 | 來電鈴聲 | 岳母：「生活費我轉過去了，省著點花！」 |
| 牌型成就（四條 / 同花順 / 皇家同花順） | 攤牌成牌 | 全螢幕特效，皇家同花順有專屬「加冕」動畫 | 專屬 stinger | 系統音：「成就解鎖：牌桌之王。」 |
| 表情互動 | 玩家點選表情 | 表情飛向目標玩家（丟番茄、灑花、比心） | 對應音效 | — |
| 離桌 | 玩家離開 | 頭像淡出 | — | Tony：「慢走，老位子給您留著。」 |

**效能原則**：所有特效可在設定中切「完整 / 精簡 / 關閉」，低階手機預設精簡；任何特效都不能阻擋牌局節奏，長特效（Bad beat、皇家同花順）上限 3 秒且可點擊跳過。

## 8. 造型系統（積分兌換）

### 8.1 造型類別

| 類別 | 說明 | 範例 |
|---|---|---|
| 頭像框 | 圍繞頭像的框 | 「霸總金框」「贅婿破布框」「惡毒女配玫瑰框」 |
| 卡背 | 底牌背面圖樣 | 「合約書卡背」「劇本卡背」 |
| 桌布 | 牌桌表面 | 「會所包廂」「豪門客廳」「城中村天台」 |
| 籌碼樣式 | 籌碼外觀 | 「金條」「排骨」（岳母梗） |
| 入場動畫 | 入桌時播放 | 「保鏢開道」「潑咖啡登場」 |
| 勝利動畫 | 贏大鍋時播放 | 「金幣雨」「簽約成功」 |
| 語音包 | 把預設旁白換成特定角色 | 「全程岳母碎念」「系統音純淨版」 |
| 稱號 | 顯示在暱稱旁 | 「三年之期已到」「牌桌吃瓜第一線」 |

### 8.2 稀有度與定價（積分 DP）

| 稀有度 | 定價區間 | 取得方式 |
|---|---|---|
| 普通 | 100–300 | 商店常駐 |
| 稀有 | 500–1,000 | 商店常駐 |
| 史詩 | 2,000–3,000 | 賽季限定 |
| 傳說 | 5,000+ | 賽季通行證最後一格 / 成就解鎖 |

- 以每日打 30 手、完成任務估算，一般玩家每天約可得 80–150 DP，普通造型 2–3 天可換一件，史詩約 3 週，讓賽季內有明確目標。

### 8.3 預設外觀
- 訪客與新註冊玩家都有一套「群演套裝」（素色框、基本卡背、Tony 預設旁白），確保沒有造型也不難看。

## 9. 技術架構建議（只定方向，不寫碼）

### 9.1 整體
- **前端**：Web 優先（手機瀏覽器 + 桌面），之後可用 PWA 或包殼上架。建議 React + 一個 2D 動畫方案（Pixi.js 或 Lottie 處理特效，CSS 動畫處理 UI）。
- **後端**：Node.js（TypeScript），WebSocket 做即時牌局，REST 做帳號 / 商店。
- **資料庫**：PostgreSQL（帳號、積分、造型、戰績），Redis（牌桌即時狀態、配桌佇列、每日限額計數）。
- **部署**：先單區域，牌桌伺服器可水平擴展（每桌一個房間，由房間 ID 路由）。

### 9.2 牌局引擎（伺服器權威）
- 所有發牌、比牌、結算只在伺服器執行，客戶端只收「對自己可見」的資訊，底牌永遠不廣播。
- 牌局以**狀態機**實作：`WaitingForPlayers → PreFlop → Flop → Turn → River → Showdown → Settlement`。
- 事件驅動：伺服器送出的每個事件（`CARD_DEALT`、`PLAYER_ALL_IN`、`POT_AWARDED`、`BAD_BEAT`…）直接對應第 7 章的特效表，前端只做「事件 → 表演」的對映，邏輯與表現分離。
- RNG：使用密碼學安全亂數，每手牌記錄洗牌種子的雜湊，之後可做「公平性驗證」頁。

### 9.3 帳號與反作弊
- 訪客用裝置產生的長效 token；註冊後與帳號綁定。
- 反串通：同一好友桌 IP / 裝置重疊偵測、積分上限、異常勝率標記。
- 禁止客戶端自報結果，任何數值變更都由伺服器事件驅動。

### 9.4 內容可熱更新
- 角色、台詞、音效、造型都以**資料檔（JSON）+ 素材包**管理，不寫死在程式裡，方便換賽季、做聯名包、或切換到正版授權素材。

## 10. 資料模型概要

- **User**：id、type（guest / registered）、nickname、auth providers、created_at。
- **Wallet**：user_id、chips、drama_points、last_daily_claim、bailout_claimed_at。
- **CosmeticItem**：id、category、rarity、price、season_id、asset_ref。
- **UserCosmetic**：user_id、item_id、equipped。
- **Table**：id、type（match / private）、blinds、max_players、owner_id、config。
- **HandHistory**：id、table_id、seed_hash、actions[]、result、timestamps。
- **PointLedger**：user_id、delta、reason、hand_id（可追溯、防刷用）。
- **Season / Quest / Achievement**：賽季、任務、成就定義與進度。

## 11. 開發階段切分

### Phase 0：定案（1 週）
- 確認 IP 路線（A 致敬 / B 授權）。
- 確認美術風格（短劇海報風：高飽和、金色標題字、浮誇光效）。
- 角色設定與台詞初稿（每角色每事件 3 句）。

### Phase 1：MVP — 能打牌（4–6 週）
- 訪客帳號、大廳、匹配桌（含 NPC 補位）、好友桌（房號加入）。
- 完整德撲引擎 + 邊池 + 斷線保護。
- 基本動畫（發牌、下注、All-in、贏鍋）+ 字幕式台詞（TTS 暫代）。
- 每日免費幣、破產救濟。

### Phase 2：情緒價值（3–4 週）
- 完整特效事件表（Bad beat、Bluff 打臉、連勝、牌型成就）。
- 自適應 BGM、角色語音配音。
- 表情互動、觀戰席。

### Phase 3：成長與收集（3–4 週）
- 註冊 / 第三方登入、訪客轉正。
- 積分、每日任務、商店、造型裝備與展示。
- 第一個賽季、排行榜、成就。

### Phase 4：營運（持續）
- 賽季內容輪替、聯名包、反作弊調整、數據監控（留存、每日手數、積分流向）。

## 12. 待你決定的事項

1. **IP 路線**：先走原創致敬（A），還是一開始就要談授權（B）？
2. **平台**：Web 優先可以嗎？還是一定要 iOS / Android 原生 App？
3. **語言**：第一版只做繁中，還是繁中 + 簡中？（短劇受眾兩岸都有）
4. **配音**：第一版用 TTS 暫代可接受嗎？之後再找配音。
5. **商業化**：確定第一版完全不收費？還是預留「付費加速解鎖造型」？
6. **NPC**：匹配桌允許 NPC 補位，還是寧可等真人？

確認以上後即可進入 Phase 0 的角色設定與台詞表細化。
