# 短劇題材參考資料（公開資訊整理）

> 範圍：只整理公開報導中的平台概況、題材與梗的類型，作為原創角色與台詞的靈感來源。
> 不包含：任何劇集影片、劇照、配樂、逐字台詞或平台 UI 素材（有版權，不收錄、不抓取）。
> 資料品質：以下搜尋結果偏商業與監管報導，題材與台詞細節很少，缺口列在最後。

  來源：[woshipm](https://www.woshipm.com/share/6231997.html)、[huxiu](https://www.huxiu.com/article/4860854.html)

  來源：[ithome](https://www.ithome.com/0/945/439.htm)

  來源：[jiemian](https://www.jiemian.com/article/13092330.html)

  來源：[cbgc.scol](https://cbgc.scol.com.cn/news/7748863)

  來源：[jiemian](https://m.jiemian.com/article/13874324.html)

  來源：[bjnews](https://m.bjnews.com.cn/detail/1780730730129801.html)

**對本專案的意義**：
- 現實題材與正向價值是平台趨勢，牌桌角色避免羞辱性、暴力性的梗，改用「誇張但無傷」的打臉。
- 版權與 AI 內容管理趨嚴，更支持採用原創素材的路線。

## 3. 經典桥段（梗的結構）

- **刷卡失敗**：炫富者被冷落的主角羞辱，結帳時才發現帳戶被凍結。
  → 牌桌版：對手大加注裝強，結果被你跟注翻牌，「籌碼被凍結」。
- **吟詩作對**：古裝劇主角突然展示才學，致敬《唐伯虎點秋香》。
  → 牌桌版：古風主題包的贏牌台詞（賽季內容）。
- **台詞模板化**：觀眾會把制式台詞套用到現實調侃。
  → 設計方向：台詞做成「可被玩家轉貼」的短句，並避免只有一種句型。
